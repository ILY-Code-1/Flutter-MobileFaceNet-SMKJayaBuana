Dokumen User Acceptance Testing (UAT)
Aplikasi Absensi Wajah SMK Jaya Buana

User Acceptance Testing memastikan aplikasi memenuhi kebutuhan pengguna akhir. Skenario ditulis dari sudut pandang pengguna. Role penguji terdiri atas Admin (operator tata usaha pengelola terminal) dan Siswa (pengguna absensi), sesuai aktor pada use case diagram. Setiap fitur utama diuji minimal satu skenario.

NoSkenario PengujianRole yang MengujiFitur yang DiujiLangkah PengujianEkspektasi HasilStatus
1 Admin menyiapkan akun pada pemasangan pertama aplikasi Admin Registrasi Akun Admin Buka aplikasi pertama kali, isi username, buat PIN 6 digit, lalu konfirmasi PIN yang sama Akun admin terbuat, data kelas & siswa contoh tersedia, aplikasi langsung menampilkan layar kamera absensi Pass
2 Siswa melakukan absensi masuk dengan memindai wajah Siswa Melakukan Absensi Wajah (Check-in) Berdiri menghadap kamera terminal, tekan "Mulai Scan", lalu pilih "Clock In" saat data dikenali Wajah dikenali, nama & kelas siswa tampil, jam masuk tersimpan, halaman sukses "Selamat datang" muncul Pass
3 Siswa melakukan absensi pulang setelah jam pulang sekolah Siswa Melakukan Absensi Wajah (Check-out) Scan wajah setelah pukul 15:30, lalu pilih "Clock Out" Jam pulang tersimpan, halaman sukses "Sampai jumpa" muncul Pass
4 Siswa yang belum terdaftar mencoba absen Siswa Melakukan Absensi Wajah (validasi) Scan wajah yang belum pernah didaftarkan Muncul pemberitahuan "Wajah tidak dikenali" dan absensi tidak tercatat Pass
5 Admin membuka menu pengelolaan dari layar kamera Admin Masuk Menu Admin Tekan ikon menu di layar kamera, masukkan PIN admin yang benar Halaman menu admin (Students, Reports, Settings) terbuka Pass
6 Admin mendaftarkan siswa baru beserta wajahnya Admin Kelola Data Siswa Buka Students, tekan "Enroll face", isi nama & NIS, pilih kelas, unggah pas-foto, proses embedding, lalu Submit Siswa baru tersimpan dan muncul pada daftar siswa siap dipakai untuk absensi Pass
7 Admin mengoreksi data siswa yang keliru Admin Kelola Data Siswa (ubah) Buka Students, ketuk salah satu siswa, perbarui nama/kelas, lalu Submit Perubahan data siswa tersimpan dan tampil pada daftar Pass
8 Admin menambah kelas baru untuk tahun ajaran Admin Kelola Data Kelas Buka Settings, tekan "Add class", masukkan nama kelas, lalu Save Kelas baru muncul pada daftar kelas dan dapat dipilih saat menambah siswa Pass
9 Admin meninjau rekap kehadiran siswa per bulan Admin Lihat Laporan Absensi Buka Reports, atur filter kelas dan periode, amati tabel rekap Rekap Hadir/Terlambat/Absen per siswa beserta persentase kehadiran ditampilkan dengan benar Pass
10 Admin melihat rincian absensi seorang siswa Admin Lihat Laporan Absensi (detail) Pada halaman Reports, ketuk baris nama siswa Dialog rincian absensi harian siswa tersebut tampil Pass
11 Admin mengekspor laporan absensi untuk arsip sekolah Admin Ekspor Laporan PDF Pada halaman Reports, tekan "Export PDF", lalu bagikan atau simpan berkas PDF terbentuk: halaman ringkasan rekap diikuti satu halaman detail per siswa berisi jam check-in & check-out harian, rapi dan dapat dibagikan/dicetak Pass
12 Admin mengatur jam sekolah dan kelas aktif terminal Admin Atur Pengaturan Aplikasi Buka Settings, ubah jam masuk/pulang, aktifkan kelas tertentu, ubah nama perangkat & suara scan Seluruh pengaturan tersimpan dan diterapkan pada proses absensi berikutnya Pass
13 Admin melaporkan kendala aplikasi ke developer Admin Hubungi Developer & Backup Database Buka menu admin, tekan tombol "Contact developer" di footer kiri WhatsApp developer terbuka berisi pesan keluhan yang sudah terisi otomatis, siap dikirim Pass
14 Admin mencadangkan database untuk dikirim ke developer Admin Hubungi Developer & Backup Database Buka menu admin, tekan tombol "Backup Database" di footer kanan, lalu pilih aplikasi tujuan pada lembar berbagi Aplikasi membuat berkas cadangan database (.sql) terkini lalu membuka lembar berbagi berisi berkas tersebut, siap dikirim ke developer Pass
