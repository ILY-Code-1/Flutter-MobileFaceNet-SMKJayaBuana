Desain Basis Data NoSQL (Firebase Firestore)
Aplikasi Absensi Wajah SMK Jaya Buana

Dokumen ini merancang struktur basis data Cloud Firestore untuk aplikasi absensi siswa berbasis pengenalan wajah (MobileFaceNet). Aplikasi bekerja sebagai terminal absensi: siswa memindai wajah untuk check-in / check-out, sedangkan admin mengelola siswa, kelas, laporan, dan pengaturan melalui menu yang dikunci PIN.

1. Strategi Pemodelan NoSQL

Desain ini menggunakan kombinasi strategi Referencing dan Embedding, dengan Referencing sebagai strategi dominan.

Referencing dipakai untuk relasi antar entitas yang tumbuh tanpa batas:

  • Koleksi attendance dipisahkan dari students karena setiap siswa menghasilkan satu dokumen absensi setiap hari sekolah. Jika absensi di-embed ke dalam dokumen siswa, ukuran dokumen akan terus membengkak hingga melewati batas 1 MB per dokumen Firestore. Maka tiap dokumen attendance hanya menyimpan studentId sebagai referensi.
  • Koleksi students menyimpan classId sebagai referensi ke koleksi classes, sehingga satu kelas (mis. "XI · RPL · A") dapat dipakai banyak siswa tanpa duplikasi nama kelas.

Embedding dipakai untuk data berukuran tetap dan kecil yang selalu diakses bersama dokumen induknya:

  • Vektor embedding wajah (192 angka float hasil MobileFaceNet) di-embed langsung di dalam dokumen siswa, karena vektor ini berukuran tetap dan selalu dibutuhkan saat proses pencocokan wajah (matchAgainst).
  • Seluruh pengaturan terminal di-embed dalam satu dokumen settings/app (jam masuk, jam pulang, kelas aktif, nama perangkat, suara scan) karena jumlahnya tetap dan selalu dimuat sekaligus saat aplikasi dijalankan.

Contoh konkret: ketika seorang siswa bernama "Andini Pratiwi" (NIS 2401001) melakukan check-in, aplikasi membaca dokumen di students beserta vektor embedding-nya (embedding), lalu menulis satu dokumen baru di koleksi attendance yang merujuk ke studentId miliknya (referencing).

2. Struktur Koleksi (Collection Structure)

Lima koleksi tingkat atas. Pengaturan disimpan sebagai dokumen tunggal beridentitas tetap app.

  • admin (koleksi) — akun admin terminal
    • {adminId} — mis. adm_01
      • username : string — "operator-tu"
      • pinHash : string — SHA-256 dari PIN
      • createdAt : timestamp
  • classes (koleksi) — daftar kelas sekolah
    • {classId} — mis. cls_xi_rpl_a
      • name : string — "XI · RPL · A" (unik)
      • createdAt : timestamp
  • students (koleksi) — siswa terdaftar beserta data wajah
    • {studentId} — mis. std_2401001
      • name : string — "Andini Pratiwi"
      • nis : string — "2401001" (unik)
      • classId : string — referensi → classes/{classId}
      • photoPath : string — lokasi pas-foto
      • embedding : array<number> — 192 nilai float
      • isDraft : boolean — true bila belum lengkap
      • createdAt : timestamp
  • attendance (koleksi) — catatan absensi per siswa per hari
    • {attendanceId} — mis. std_2401001_2026-05-21
      • studentId : string — referensi → students/{studentId}
      • date : string — "2026-05-21" (format YYYY-MM-DD)
      • checkInTime : string — "07:02:14"
      • checkOutTime : string — "15:35:40"
      • status : string — "present" | "late" | "absent"
  • settings (koleksi) — pengaturan terminal absensi
    • app — dokumen tunggal konfigurasi
      • activeClassIds : array<string> — kelas yang dikenali terminal
      • clockIn : string — "07:00"
      • clockOut : string — "15:30"
      • lastCheckOut : string — "18:00"
      • deviceName : string — "Terminal 1"
      • soundOnScan : string — "soft_chime"

Relasi referensi: students.classId → classes.{classId}  |  attendance.studentId → students.{studentId}.

3. Logical Structure (Object Diagram)

Diagram objek berikut menggambarkan contoh dokumen nyata dari tiap koleksi serta tautan referensi antar dokumen.

@startuml
object "admin/adm_01" as Admin {
  username = "operator-tu"
  pinHash = "9f86d081...e2d5"
  createdAt = 2026-05-01T08:00:00
}

object "classes/cls_xi_rpl_a" as Kelas {
  name = "XI · RPL · A"
  createdAt = 2026-05-01T08:05:00
}

object "students/std_2401001" as Siswa {
  name = "Andini Pratiwi"
  nis = "2401001"
  classId = "cls_xi_rpl_a"
  photoPath = "/faces/student_174..._.jpg"
  embedding = [0.041, -0.118, ... ]
  isDraft = false
  createdAt = 2026-05-01T08:10:00
}

object "attendance/std_2401001_2026-05-21" as Absensi {
  studentId = "std_2401001"
  date = "2026-05-21"
  checkInTime = "07:02:14"
  checkOutTime = "15:35:40"
  status = "present"
}

object "settings/app" as Setting {
  activeClassIds = ["cls_xi_rpl_a","cls_xi_mm_a"]
  clockIn = "07:00"
  clockOut = "15:30"
  lastCheckOut = "18:00"
  deviceName = "Terminal 1"
  soundOnScan = "soft_chime"
}

Siswa --> Kelas : classId
Absensi --> Siswa : studentId
Setting --> Kelas : activeClassIds
@enduml
