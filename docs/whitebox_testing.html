Code traceability: lib/core/utils/pin_validator.dart — baris 14–38

Fungsi ini memvalidasi PIN admin 6 digit: harus tepat 6 digit, hanya angka, tidak semua digit sama, dan bukan deret berurutan naik/turun.

else (tidak)
endif

  stop

  :return best (wajah cocok);
  stop
endif
